Meow Client

A lightweight PvP + Visuals client for Minecraft 1.21.11 (Fabric).

Download Meow Client View on GitHub
v1.0.0  ·  1.21.11  ·  Fabric

What's inside

⚔️

PvP

Keystrokes, CPS counter, combo tracker, reach display, armor HUD, potion HUD and more.
🖥️

HUD

FPS, coords, ping, biome, session timer, memory, server IP — fully draggable in a HUD editor.
✨

Visuals

Zoom, fullbright, custom sky, particles control, hitboxes, nametags, capes and cosmetic wings.
🐱

ClickGUI

Full-screen pink interface opened with Right Shift. Toggles, sliders, dropdowns, and a color picker.
⚙️

Config

Every module and setting saves to JSON automatically. Reloads exactly how you left it.
💖

Server-safe

No hacks, no exploits. Every module is client-side and legit — safe on Hypixel, Minemen, PvP Legacy.
