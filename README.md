# 🐱 Meow Client — Website

Official landing page for **Meow Client**, a lightweight PvP + Visuals client for **Minecraft Java 1.21.11** running on **Fabric**.

**Live site:** https://echothebest.github.io/meow-website/

---

## What is this?

This is a **static website** — plain HTML, CSS, and JavaScript. No frameworks, no build step, no npm. Just open `index.html` or drop it on GitHub Pages.

---

## Pages

- `index.html` — homepage with terminal intro animation, hero, features, download
- `features.html` — full list of modules by category
- `faq.html` — frequently asked questions
- `changelog.html` — version history
- `contact.html` — contact form (static, demo only)
- `terms.html` — terms of service
- `privacy.html` — privacy policy

---

## Features

- 🎬 **Terminal intro animation** — types out lines one by one on first visit, skips on refresh
- ✨ **Animated starfield** background on every page
- 🐱 **Pink cat theme** matching the Meow Client GUI
- 📱 **Fully responsive** — mobile, tablet, desktop
- ⚡ **Zero dependencies** — pure vanilla HTML/CSS/JS
- 🎨 **Single theme file** — change one CSS variable to retheme everything
